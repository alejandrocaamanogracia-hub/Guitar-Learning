# 🎸 Fretboard Trainer

Aplicación web interactiva desarrollada en **JavaScript** diseñada para ayudar a guitarristas a memorizar y dominar las notas en el diapasón de la guitarra de forma dinámica.

## 🚀 Modos de Juego
1. **Find the Note:** El sistema te indica el nombre de una nota y debes encontrarla y hacer clic en el traste y cuerda correctos del diapasón.
2. **Guess the Note:** El sistema ilumina una posición aleatoria en la guitarra y debes pulsar el botón de la nota correspondiente en la interfaz superior.

## 🛠️ Tecnologías Utilizadas
* **HTML5 & CSS3**
* **JavaScript**
